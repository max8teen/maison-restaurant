# MAISON Spring Boot Backend

Production backend for MAISON Fine Dining.

- Java 17 + Spring Boot 3
- PostgreSQL / Supabase
- Spring Data JPA
- Spring Mail (Gmail SMTP)
- BCrypt password hashing
- Static customer and admin frontend bundled in the JAR

Run locally with Maven after setting `DATABASE_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, `MAIL_USERNAME`, and `MAIL_PASSWORD`.
