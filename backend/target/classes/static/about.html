The Project

About Maison

Maison Fine Dining is a full-stack restaurant table booking system built independently as a micro project. It allows customers to register using OTP-based email verification, browse the restaurant, book a table by selecting date, time, guests and occasion, and receive a branded confirmation email after every booking.

The admin panel gives the restaurant owner complete control — manage reservations, tables, customers, and view monthly reports and statistics. All wrapped in a premium dark-gold mobile-responsive design.
